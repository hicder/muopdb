<task type="auto">
  <name>Task 2: Create Bm25Searcher core component</name>
  <files>rs/index/src/bm25/searcher.rs</files>
  <action>Create the main search implementation in `rs/index/src/bm25/searcher.rs`:

1. **Bm25Searcher** struct:
   - `stats_reader: Bm25StatsReader` - provides per-user statistics
   - `multi_term_index: Arc<MultiTermIndex>` - provides posting list access
   - `scorer: BM25Scorer` - computes BM25 scores
   - `tokenizer: TokenizerPipeline` - tokenizes query text
   
   Constructor: `new(stats_dir: String, terms_dir: String, config: BM25Config) -> Result<Self>`
   - Initialize Bm25StatsReader from stats_dir
   - Initialize MultiTermIndex from terms_dir
   - Use BM25Scorer with provided config
   - Use TokenizerPipeline::english() as default tokenizer

2. **search() method** - the main search entry point:
   ```rust
   pub fn search(&self, query: &Bm25Query) -> Result<Bm25SearchResults>
   ```
   - Look up UserBm25StatsView for query.user_id
   - Tokenize query.text into query terms using self.tokenizer.tokenize()
   - For each query term, score documents and aggregate scores
   - Return Bm25SearchResults sorted by score (highest first)

3. **score_single_term() method** - implements QRY-01:
   ```rust
   fn score_single_term(&self, user_id: u128, term: &str, stats: &UserBm25StatsView) -> Result<HashMap<u32, f32>>
   ```
   - Get term_id from MultiTermIndex for the term
   - Get posting list iterator for the term (documents containing this term)
   - For each document in posting list:
     - Get doc_length from stats.get_doc_length(point_id)
     - Compute term frequency by counting occurrences in document
     - Get doc_freq from stats.get_term_df(term)
     - Call BM25Scorer::score() to compute score
   - Return HashMap of point_id -> score for this term

4. **score_multi_term() method** - implements QRY-02:
   ```rust
   fn score_multi_term(&self, user_id: u128, terms: &[String], stats: &UserBm25StatsView) -> Result<HashMap<u32, f32>>
   ```
   - For each term in terms, call score_single_term()
   - Aggregate scores: sum scores for each document across all terms
   - Documents matching multiple query terms get higher scores (score summation)
   - Return aggregated HashMap of point_id -> total_score

Use `anyhow::Result` for error handling. Import types from sibling modules using super:: query::, super:: scorer::, etc. Pattern match existing code style in bm25/ module.</action>
