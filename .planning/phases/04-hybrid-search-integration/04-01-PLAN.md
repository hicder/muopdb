<objective>
Implement score normalization and fusion algorithms for hybrid search. Create the mathematical foundation for combining BM25 text relevance scores with vector similarity scores.

**Purpose:** Enable proper score combination by normalizing BM25 scores (which are unbounded) to the same [0,1] scale as vector similarity scores, then fuse them with configurable weighting.

**Output:** ScoreNormalizer for min-max normalization and HybridScoreFusion for linear combination fusion.
</objective>
